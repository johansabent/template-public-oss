# Documentation

Documentation is organized by artifact type, not by tool or agent. Create a category only when it contains a real artifact, then register the category in `MANIFEST.json`.

Common categories, when justified, are `decisions`, `plans`, `references`, `reports`, `runbooks`, and `schemas`. `archive` is reserved for non-authoritative historical material and must never contain a canonical target.

Root authorities remain:

- `AGENTS.md` — evergreen agent rules
- `BOARD.md` — milestone ordering and gates
- `CONTEXT.md` — domain language and constraints
- `STATE.md` — thin current orientation
